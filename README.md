# フリマ便利ツール

Netlifyへそのままアップロードできる静的サイトです。

## 今回の主な変更

- ホームの送料一覧カードを有効化
- 利益計算画面にフリマ選択を追加
- 選択したフリマに合わせて配送方法と送料を切り替え
- 送料一覧のボタンから、フリマ・配送方法・送料を引き継ぎ
- `assets/js/shipping-data.js` に送料情報を集約
- 送料一覧と利益計算が同じ共通データを参照

## 送料改定時に変更する場所

`assets/js/shipping-data.js` だけを変更してください。
各配送データには、フリマ、配送方法、送料、規格、説明をまとめています。

## 公開方法

このフォルダ直下に `index.html` があることを確認し、フォルダ全体をNetlifyへドロップしてください。

## 送料一覧の表示

各フリマ内で「日本郵便系」「ヤマト運輸系」に分け、初期状態は折りたたみ表示です。配送会社を押すと該当する発送方法が開きます。分類は `assets/js/shipping-data.js` の `carrierId` で管理します。

## v9 更新内容

- 共通ヘッダーを画面上部へ常時固定

## v10 更新内容

- 上部メニューを「ホーム → 利益計算 → 利益逆算 → 送料一覧」の順へ変更
- ホームの便利ツールも計算系を先に並べるよう変更
- ホームの「このサイトでできること」を削除
- 各サービスの公式リンクをサービス名の直前へ2列で集約

## v11 更新内容

- サービス名と日本郵便系・ヤマト運輸系の公式リンクを1つのカードに統合
- 統合カード全体を共通ヘッダー直下へ固定
- メルカリ、ラクマ、Yahoo!フリマへ移ると固定カードも自動で切り替え
- 公式リンクとサービス名の間延びを解消


## v12 更新内容

- メルカリ・ラクマ・Yahoo!フリマをサービス単位の大きなカードで囲む構成へ変更
- サービス名・公式リンク・日本郵便系・ヤマト運輸系を同じ背景内に統合
- 配送会社はサービスグループ内の白い子カードとして表示
- サービスグループ間に余白と区切り線を追加
- 固定サービスカードの動作は維持
